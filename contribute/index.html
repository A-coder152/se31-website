Make this place yours.

Improve a source, fix a rough edge or add something everyone will genuinely use.

SE31 Nest is made by students, for students. Contributions from anyone in the cohort are welcome, whether that means correcting one date or building something new.

What would help

  • Verify a resource: Share useful links to academic tools, student life guides or developer resources.
  • Correct a public date: Keep the cohort informed with a reliable source.
  • Improve a course guide: Make an archived outline easier to understand without changing its meaning.
  • Polish the experience: Improve accessibility, design, performance or a rough interaction.

Start contributing

View the repository Open an issue ↗ Submit a pull request ↗
Want to edit the code? →

Clone the project, install its dependencies and start the local server:

git clone https://github.com/AdvancedForge/se31-website.git
cd se31-website
npm install
npm run dev

Most shared information lives in src/data/deadlines.ts, resources.ts, courses.ts and timetable.ts.

A few ground rules

  • Do not submit private personal information.
  • Do not submit unofficial deadlines without a verifiable source.
  • Do not upload copyrighted course material or sensitive academic content.
  • Be respectful and constructive in every contribution.
